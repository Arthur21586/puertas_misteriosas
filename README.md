# 🚪 Las 20 Puertas Misteriosas

### 🎮 Juego Didáctico Interactivo para el Aula

**Las 20 Puertas Misteriosas** es un juego educativo diseñado para utilizarse en el aula mediante una dinámica de preguntas, puntos, premios y desafíos.

Los estudiantes deberán abrir las misteriosas puertas del tablero y superar los diferentes retos que encontrarán en su camino.

## 🗝️ ¿Cómo se juega?

Antes de comenzar, el profesor puede configurar:

* 🚪 Cantidad de puertas.
* 👥 Número de alumnos o equipos.
* 📝 Preguntas educativas.
* ⏱️ Tiempo para responder.
* ⭐ Puntuación.
* 🚫 Puertas trampa.
* 🎁 Premios especiales.
* ⚠️ Castigos.

Durante la partida, los jugadores van abriendo las puertas una por una. Cada puerta puede esconder una pregunta, una trampa, un premio o un castigo.

Al finalizar todas las puertas, **el alumno o equipo con mayor cantidad de puntos será el ganador**.

## 🚪 Tipos de puertas

### ❓ Puertas con preguntas

Contienen preguntas de opción múltiple.

El jugador deberá responder correctamente antes de que termine el tiempo para conseguir los puntos correspondientes.

### 🚫 Puertas trampa

Algunas puertas esconden trampas.

Al encontrarlas, el jugador puede perder inmediatamente su turno.

### 🎁 Premios y castigos

Las puertas también pueden contener eventos especiales que modifican la partida.

Pueden permitir:

* ⭐ Ganar puntos.
* ➕ Obtener turnos adicionales.
* ➖ Perder puntos.
* 🚫 Perder turnos.
* 🎯 Aplicar diferentes efectos personalizados.

## 👨‍🏫 Editor para el profesor

El juego incluye un editor que permite adaptar la aventura a las necesidades de cada clase.

El profesor puede:

* Crear nuevas preguntas.
* Modificar preguntas existentes.
* Definir las opciones de respuesta.
* Seleccionar la respuesta correcta.
* Asignar puntuación.
* Configurar el tiempo para responder.
* Crear puertas trampa.
* Crear premios.
* Crear castigos.
* Configurar los efectos de los premios y castigos.
* Cambiar la cantidad de puertas.

## 💾 Importar y exportar preguntas

El contenido del juego puede **exportarse e importarse mediante archivos JSON**.

Esto permite al profesor guardar sus preguntas y reutilizarlas posteriormente.

También facilita crear diferentes bancos de preguntas para distintas materias, grupos o cursos.

## 🎯 Objetivo educativo

El juego utiliza elementos de **gamificación** para convertir las preguntas de clase en una dinámica de participación y competencia sana.

Puede utilizarse para:

* 📚 Repasar contenidos.
* 🧠 Evaluar conocimientos.
* 👥 Trabajar en equipos.
* 🎯 Realizar actividades de recuperación.
* 📝 Realizar repasos antes de un examen.
* 🏆 Motivar la participación de los estudiantes.

## ⚙️ Configuración

El juego permite seleccionar diferentes cantidades de puertas:

**10 · 20 · 30 · 40 · 50**

También permite configurar entre:

**2 · 3 · 4 jugadores o equipos**

De esta manera, el profesor puede adaptar la duración y dinámica de la actividad al tamaño de su grupo.
